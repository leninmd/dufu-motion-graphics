## 二、上线后自己抢占热评区的三条"神评"

> 发布后 3 分钟内用小号/自己账号置顶，把评论区情绪定调，引导"故事接龙"。

1. **共鸣型（最容易引发盖楼）**
   > 少不读杜甫，读懂已是书中人。
   > 二十岁读「安得广厦千万间」只当是背诵默写，三十岁在出租屋里再读一遍，才知道他写的是房租。

2. **考据型（吸引文化区用户，拉高评论质量）**
   > 补个冷知识：写这首诗的时候，他刚到成都两年，草堂是自己一砖一瓦搭的。屋顶的茅草被村里的孩子抱走了，他追不上，回来写的不是骂人，是「大庇天下寒士」。这才是最狠的地方。

3. **反转型（把"废物"那一段的钩子接住）**
   > 视频里 01:01 那句「废物」，是别人骂他的。
   > 可他五十九岁死在船上之前，写的最后一句还是「战血流依旧，军声动至今」。
   > 有些人一辈子没赢过一次，却从来没让这个国家从他心里掉出去。

## 三、把本仓库抽成《中式人物志 Video Recipe 模板》

整套工程是"数据驱动 + 分镜可换"的，复刻李白、辛弃疾、王阳明、鲁迅只需改四个地方。

### 3.1 参数替换表

| 要改的 | 位置 | 说明 |
|---|---|---|
| 人物与时间轴 | `storyboard.json` → `chapters`、`hud` | 章节起止（秒）、右上角「地点·纪年·事件·里程」 |
| 旁白文本 | `storyboard.json` → `narration` | 每句 `start` 与 `text`；改完跑 `python audio/build_audio.py --tts-only` 看时长，再微调 start |
| 诗句/金句 | `scenes/s02_typeworld.js`（红牌）、`s03`（风雨句）、`s04`（点云诗）、`s07`（叩问）、`s09`（终章） | 直接替换中文字符串 |
| 配色与字体 | `engine/aesthetics-hub/uiux-typography.js` → `P`、`F` | 想换"寒江冷调"就把 `paper` 换成冷灰、`cinnabar` 换成靛青 |

### 3.2 四种人物的"母题—意象"映射（直接照抄改字即可）

| 人物 | 母题 | 核心意象（对应本片分镜） | 终章金句方向 |
|---|---|---|---|
| **李白** | 自由与出逃 | 酒（金球→酒液）、月、剑、瀑布（竖向粒子流） | 「他把官场丢了，把月亮捡起来了」 |
| **辛弃疾** | 不甘与未竟 | 铁马冰河（刚体碎裂）、剑气（红线）、灯火（万家灯火点阵） | 「醉里挑灯看剑，梦回吹角连营」 |
| **王阳明** | 向内求索 | 竹（格竹）、石洞（圆孔穿越）、心灯 | 「此心光明，亦复何言」 |
| **鲁迅** | 清醒与呐喊 | 铁屋（刚体坍塌→众人推窗）、烟、手稿（墨字墙） | 「此后如竟没有炬火，我便是唯一的光」 |

### 3.3 复刻流程（30 分钟出一版）

```powershell
# 1. 复制配方
Copy-Item -Recurse . docs\recipes\libai      # 或直接 git clone 本仓库改名

# 2. 改数据（只改 JSON，不动代码）
notepad storyboard.json          # chapters / hud / narration
notepad scenes\s02_typeworld.js  # 红牌诗句
notepad scenes\s09_end.js        # 终章金句

# 3. 重生成音轨并测时长
python audio/build_audio.py --tts-only
python audio/build_audio.py

# 4. 逐帧渲染 + 编码
python render/render3.py frames --out output/frames --quality 96
powershell -ExecutionPolicy Bypass -File .\run_all.ps1

# 5. 质检
node engine/qa-gate.mjs
```

### 3.4 复用边界（哪些能直接搬、哪些必须重画）

- **能直接搬**：五层堆栈、颗粒/暗角、HUD、纸纹、朱印、红圈、卡片翻转、刚体坍塌框架、时间轴、字重配对、音效卡点规则。
- **必须重画**：与题材强绑定的三个"奇观镜头"（本片是：三万点云收峰、万金球体挤压、子弹时间雨珠）。它们决定片子像不像"另一个人的片"，建议每个人物都重做一个专属奇观。
- **不要复用的**：本片的具体文案与诗句（版权与立意都靠它立住）。
