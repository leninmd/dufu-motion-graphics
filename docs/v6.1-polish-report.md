### 竖屏是怎么做的（`tools/vertical.mjs`）

```bash
node tools/vertical.mjs --h 1920 --crf 16 --name 1080x1920_douyin   # 抖音主投
node tools/vertical.mjs --h 1280 --crf 21 --preset medium \
     --name 720x1280_vertical_share                                  # 轻量竖屏
```

* **不裁切**：本片每一个字、每一张时代卡、里程表、19 格展墙都是按 1920×1080 构图落位的，
  直接裁 9:16 会砍掉三分之二画面并切掉左上标题卡与右上里程表。因此竖屏版把**完整 16:9 画面**
  等比缩到 1080×608，居中浮在竖屏画幅里。
* **上下暗场**取自同一帧：缩小 → 高斯模糊 → 提饱和 → 压暗 −0.44 → 暗角，
  看起来像"暗房里的一块亮屏"，而不是色块糊墙。
* **金色发丝边框**（`0xC8A456 @34%`）—— 与全片的鎏金画廊框同源。
* 强制 `setsar=1`：否则 `scale` 会保留显示宽高比去改写像素宽高比，
  手机端会把竖屏文件当 16:9 播放（本项目第一次生成时确实踩过这个坑）。
* 画面中心位于 y≈960，底部 656 px 全黑，正好让开抖音的字幕条与右侧互动按钮。
